# Implementation decisions and deviations from the paper

Format: **Paper** → **Implemented** → **Why / consequence**.

1. **Graph extraction.** Paper: LLM-assisted entity/relation extraction (Sec. 3.1, [12]). → Rule-based capitalised-phrase extraction; edges = sentence co-occurrence with the connecting text as relation label; passage title is a hub entity. → No LLM needed, auditable, free; but lower recall/precision (misses lower-case entities, splits some names). Ablation A8 (extraction noise) is therefore *not* run. State this limitation in the paper.
2. **Entity linking.** Paper: link mentions to nodes. → exact normalised match, then token-Jaccard ≥ 0.5, then verbatim node-name match in the question (excluding a few generic words). Thresholds are my choice.
3. **Graph proximity (Eq. 5).** → BFS hop distance from nearest linked query entity, `g = 1/(1+dist)`, `max` over entities in the passage. Ties broken by proximity mass `Σ 1/(1+dist)` (paper silent). BFS expands at most 25 highest-weight neighbours per node to bound hub explosion. PPR available via `retrieval.proximity: ppr` (A5).
4. **Fusion (Eq. 4).** Implemented as written: min-max normalisation, `ŝ_vec = 0` for passages not from the vector path, γ = 0. Consequence: graph-only passages never receive a vector score, which penalises them. α/β are config values; the paper says to tune on dev — a grid search script is **not** included (set in config; document values used). RRF is available (A4).
5. **De-duplication / budget.** Cosine > θ_dup skip + token budget (whitespace tokens, not model tokens).
6. **Hop estimator.** Paper: small classifier for ĥ(q). No hop labels exist → transparent heuristic counting nested-reference cues (`of the`, `that`, `whose`, `where`, `who`), capped at 4. A trained estimator is future work.
7. **Rule router.** Paper: simple→V, medium→H, complex→G. Concrete thresholds: complex if ĥ ≥ 3; medium if comparison cue or ĥ ≥ 2; else simple; no linkable entity → vector. These are hypotheses, not validated.
8. **Learned router.** Eq. 1 as multinomial logistic regression on standardised features (softmax). Eq. 2 cost-aware selection with measured Ĉ(r) = mean of min-max normalised median latency and median prompt tokens from the **train** split. Eq. 3 labels from train-split runs only (ε configurable). τ_r tuned on **dev** by looking up per-route F1 from dev runs (no extra generation). `top1_sim` feature exists but is 0 unless a `top1_fn` is supplied (costs a vector search). Degenerate case: if all train labels are identical the router returns that class.
9. **Oracle.** Eq. 3 applied to the evaluated questions themselves using ground truth; flagged `oracle=True`; upper bound only.
10. **Verification.** Eq. 6–7 and accept/qualify/abstain as written. Claims = the model's ≤3 stated supporting facts + the final answer (no separate claim-extraction LLM call). ENT backends: `lexical` (token containment; offline weak proxy, used automatically with the mock LLM) or `llm` (prompted JSON judge; same model as generator ⇒ **not independent**). The paper's "triple exists in G" check and an NLI model are **not** implemented. Malformed/failed verifier output counts as *not supported* (conservative). Abstention replaces the final answer with an empty string (original preserved in `original_answer`).
11. **Faithfulness metric.** Paper asks for an evaluator independent of the verifier (e.g. RAGAS). **Not implemented**; κ is reported but is the verifier scoring itself. A manual audit is left to the authors.
12. **B0 / B4 / oracle** added exactly as in paper Table 4.1. The master prompt's five baselines are a subset and are all present.
13. **Splits.** HotpotQA test labels are not public → sample from official *validation* (distractor), then 50/20/30 train/dev/test by seed. Corpus = union of all context paragraphs of the sampled questions (pooled, so distractors from other questions act as hard negatives — harder than per-question distractor setting).
14. **Mock LLM.** An extractive heuristic with crude 2-hop chaining so the pipeline can run offline. It is not a language model; its results must never be reported.
15. **Embedding fallback.** `tfidf` (hashed n-gram vectors) when sentence-transformers is unavailable. Index files record the embedder name and refuse to load with a different one.
16. **Not implemented:** MuSiQue/NQ end-to-end validation, cross-encoder reranker (A6 covers only dedup on/off), A2 feature-ablation, A8, external HippoRAG/LightRAG reference, manual audit tooling, repeated-run variance (single run; the mock/temperature-0 setting does not remove hosted-model nondeterminism).
